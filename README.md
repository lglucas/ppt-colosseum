# ppt-colosseum

Apresentação animada (HTML/CSS/JS) sobre o hackathon **Colosseum — Crypto World's Fair**, feita para a **Superteam Brasil** usar na divulgação do evento aos builders brasileiros: dados atualizados da Solana, as regras da nova edição (premiação, trilhas de protocolo, aceleradora) e uma metodologia própria para priorizar sidetracks.

## Ver a apresentação

- **Arquivo único** — [`crypto-worlds-fair-standalone.html`](./crypto-worlds-fair-standalone.html): todas as imagens embutidas no próprio HTML (~4 MB). Baixa, abre no navegador (duplo clique) e funciona **offline** — dá pra mandar direto por WhatsApp ou e-mail como um único anexo.
- **Versão de produção** — [`index.html`](./index.html) + pasta [`assets/`](./assets): mesmo conteúdo, mas com as ~30 imagens/ícones como arquivos separados. Mais leve para versionar e editar; precisa manter a pasta `assets/` ao lado do HTML. É essa versão que o GitHub Pages serve, se ativado neste repositório.

## Navegação no deck

- Setas do teclado `←` `→`, ou clique nos botões no canto inferior direito
- Swipe (arrastar) em telas de toque
- Pontinhos de progresso na base — coloridos por parte (azul = Parte 1, lilás = Parte 2, terracota = Parte 3, verde = fechamento) e clicáveis para pular direto

## Estrutura do conteúdo (21 slides)

| Parte | Slides | Conteúdo |
|---|---|---|
| **1 — Por que Solana** | 1–5 | Números de mercado atualizados, velocidade da rede (upgrade de slot time em andamento), adoção institucional |
| **2 — A nova edição** | 6–13 | Formato (4 semanas), premiação total de $840.000, as 8 trilhas de protocolo, aceleradora ($2,5M), requisitos de submissão, 7 critérios de avaliação, processo e prazos |
| **3 — Sidetracks** | 14–20 | O que são, prova histórica (54 sidetracks no Frontier), metodologia de 4 tiers para priorizar quais vale a pena perseguir, e como aplicar isso ao seu próprio projeto |
| **Fechamento** | 21 | Marca Superteam Brasil, link para [hackathon.superteam.com.br](https://hackathon.superteam.com.br/) e QR code para o grupo oficial do WhatsApp — design nas cores do site da Superteam Brasil, deliberadamente distinto do resto do deck |

## Fontes dos dados

Os números da Solana e as regras do hackathon foram verificados contra fontes públicas (Blockworks, DefiLlama, site oficial da Solana Foundation, colosseum.com, superteam.fun) em setembro de 2026. Detalhes de cada atualização estão no [CHANGELOG.md](./CHANGELOG.md).

Reproduzidos aqui como material de divulgação oficial do evento, não como trabalho original deste repositório.
